## ⚙️ How to Use

Each problem folder is self-contained:

```bash
# Compile a solution
javac 0015-3sum/0015-3sum.java

# Run it against your own test harness / main method
java -cp 0015-3sum Solution
```

Solutions follow LeetCode's `class Solution` convention, so they can be pasted directly into the LeetCode editor for testing.
