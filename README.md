# 📌 Solution Format

Each solution should follow this structure:

```text
Problem
↓
Approach
↓
Algorithm
↓
Java Implementation
↓
Time Complexity
↓
Space Complexity
```

Example:

```java
// Codeforces: 71A - Way Too Long Words
// Difficulty: 800
// Topic: Strings / Implementation

import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        int n = sc.nextInt();

        while (n-- > 0) {
            String s = sc.next();

            if (s.length() > 10) {
                System.out.println(
                    s.charAt(0) + "" +
                    (s.length() - 2) +
                    s.charAt(s.length() - 1)
                );
            } else {
                System.out.println(s);
            }
        }
    }
}
```
